# Eudaspace Calm Home Directory (static site)
Open via any static host. Locally: `python3 -m http.server 8765` in this folder, then visit http://localhost:8765/
- index.html, about.html, styles.css, app.js
- data/listings.json: public data (fit scores deliberately excluded)
- assets/eudaspace-logo.png: Eudaspace wordmark from eudaspace.co.uk (Wix media 2553e1_68694e59...)
Full data incl. hidden fit scores: /workspace/calm-home-site-private/listings-full.json and /workspace/calm-home-directory.csv
